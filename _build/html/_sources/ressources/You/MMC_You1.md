# Sujets amorcés en MMC
 * déformation (vecteur D, colonnes du tenseur)
 * défo plane/contrainte plane : quand faire le choix de l'une ou l'autre, les limites
 * "facette" : lien avec représentaton des cercles de mohr
 * base principale pour tenseur contrainte et pour tenseur défo
 * traces -> ce que cela représente (défo ; contrainte)
 * cisaillement (zoom sur l'équilibre en moment)
 * relations de comportement (3D, 1D)
 * tenseurs dans base cylindrique ou cartésienne

 * équivalence cinématique des conditions limites dessinées sous forme de "liaison" ou de "charge"
 * équivalences locales/globales pour chargements répartis
 * Tint = + ou - Text
 * conditions aux limites dans le cas de problèmes symétriques. 
 * gauchissement dans les poutres en torsion
 * hyp de Navier-Bernoulli (sections droites restent droites)

 * théorèmes énergétiques
