L'idée est d'identifier une liste de <strong>points clefs</strong>, de <strong>zooms</strong> à faire. <br>
Les fiches réalisées ne remplacent donc pas un cours, mais apporte une vision complémentaire, imagée, appréhendable avec les mains. <br>
N'hésitez donc pas à êre précise ou précis sur ce que vous ne comprenez pas si vous souhaitez compléter la liste.<br>
<br>
Il est aussi possible que vous ayez sur certaines notions vécu l'éffet 
<span style="color: blue;">"aaaaaaaaaaaahhh mais c'est ça !!!"</span>, n'hésitez pas à partager vos petites recettes! Je pourrai peut-être en faire bénéficier un plus grand nombre en la partageant !
</div>

*La plupart des sujets proposés sont directement dans les fiches associées à chaque champs disciplinaire*


# Sujets généraux amorcés
 * analogies/équivalences multiphysiques élec/thermique/méca/hydrau
 * les paradoxes de calcul (calculer une grandeur sur le résultat d'un calcul fait sous hypothèse négligeant l'ordre de grandeur de cette meme variable (HPP, rendements, ...))
 * parallèles essai physique et essai numérique (système, sources, mesures, débug, etc )
 * maths : interprétation graphique : dérivées, der2, continuité, échelles, maps, ...
 * invariants : norme, trace, det ...
 * ...


# Vos suggestions/besoins généraux ou non proposés dans les autres menus

 * cotation GPS, comment quantifier
 * méthodo pour aborder un pb méca à résoudre
 * thermo : équation de la chaleur
 * ...
